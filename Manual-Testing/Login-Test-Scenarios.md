# Login Page Test Scenarios

## Objective
To identify the major areas that should be tested on a login page.

## Test Scenarios

| Scenario ID | Test Scenario |
|---|---|
| TS_LOGIN_001 | Verify login with valid credentials |
| TS_LOGIN_002 | Verify login with an invalid username |
| TS_LOGIN_003 | Verify login with an incorrect password |
| TS_LOGIN_004 | Verify validation when both fields are empty |
| TS_LOGIN_005 | Verify validation when the username is empty |
| TS_LOGIN_006 | Verify validation when the password is empty |
| TS_LOGIN_007 | Verify password masking |
| TS_LOGIN_008 | Verify password field behavior when show/hide is available |
| TS_LOGIN_009 | Verify login using the Enter key, if supported |
| TS_LOGIN_010 | Verify behavior after repeated failed login attempts |
| TS_LOGIN_011 | Verify the Forgot Password link, if available |
| TS_LOGIN_012 | Verify the Remember Me option, if available |
| TS_LOGIN_013 | Verify logout and subsequent login |
| TS_LOGIN_014 | Verify login page behavior on supported browsers |
| TS_LOGIN_015 | Verify login page layout on supported screen sizes |

## Notes
- These are sample scenarios, not execution results.
- Optional features should be tested only if the application supports them.
- Actual results must be recorded after testing a real application.
